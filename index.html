À propos de ce projet

Cette application web présente les résultats de l'analyse des différentes stations étudiées dans le cadre d'un stage sur l'implémentation de la méthodologie ShiftHappens pour l'estimation de détarages après évènements extrêmes dans l'arc alpin.

About this project

This web application presents the analysis results for the various monitoring stations studied during an internship focused on implementing the ShiftHappens methodology to estimate rating curve shifts following extreme events in the Alpine arc.
